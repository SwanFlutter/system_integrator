# system_integrator

Flutter **FFI plugin** (Windows, macOS, Linux) for download-manager style apps:
open/reveal files, Storage Usage / Disk Pressure, low-space warnings,
"shut down when downloads finish", launch at startup, tray icon.

## Project structure (FFI plugin template)

* `src/` – native C sources built into **one** dynamic library
  (`system_integrator.dll` / `libsystem_integrator.so` / `system_integrator.framework`).
  * `system_integrator.h` – the C API (input of ffigen)
  * `system_integrator.c` – shared code; includes `platform/windows.inc`,
    `platform/macos.inc` or `platform/linux.inc`
  * `system_integrator_tray.m` – macOS NSStatusItem tray (Objective-C)
  * `CMakeLists.txt` – Windows/Linux build (links Win32 libs / GTK)
* `macos/Classes/` – forwarders that `#include` the `src/` files (podspec).
* `linux/`, `windows/` – template CMake files that `add_subdirectory(../src)`.
* `lib/system_integrator.dart` – `DynamicLibrary` + generated bindings + helper
  isolate (same pattern as the template's `sumAsync`) + the `SystemIntegrator` API.
* `lib/system_integrator_bindings_generated.dart` – generated by
  `dart run ffigen --config ffigen.yaml`.

### Hybrid architecture

| Layer | What |
|---|---|
| Dart `Process.run` | macOS/Linux built-in tools: `open`, `open -R`, `osascript`, `pmset`, `xdg-open`, `gdbus`, `shutdown`, `systemctl` |
| Dart file I/O | LaunchAgents plist, XDG autostart `.desktop` |
| FFI → `src/` | disk counters (`GetDiskFreeSpaceExW` / `statfs` / `statvfs64`), volume enumeration, Win32 (ShellExecuteW, SHOpenFolderAndSelectItems, InitiateSystemShutdownExW, SetSuspendState, HKCU Run) |
| FFI → `src/` tray module (UI-bound) | `Shell_NotifyIconW` on its own message-loop thread · `NSStatusItem` on the main queue · AppIndicator (StatusNotifierItem over DBus, `dlopen`) / GtkStatusIcon on the GTK main context. Events reach Dart through `NativeCallable.listener` |

Blocking probes (`si_list_volumes`, `si_get_disk_space`) run on the helper
isolate, never on the UI isolate. No admin/root rights are needed.

## Usage

```dart
final si = SystemIntegrator.instance
  ..configure(appId: 'com.example.downloader', appName: 'Example Downloader');

final caps = await si.capabilities();          // hide / disable UI from this

await si.openFile(path);
await si.revealInExplorer(path);                // selected in Explorer / Finder
await si.copyToClipboard(path);

final vols = await si.listVolumes();            // Storage Usage card
si.watchVolumes().listen(updateCard);           // emits only when a value changes
si.onLowSpace(freeBytesThreshold: 5 << 30).listen(warn); // once per crossing

// download_engine pre-flight disk guard
final engine = DownloadEngine(freeSpaceProbe: si.freeSpaceOf);

await si.prepareShutdownPermission();           // macOS: consent prompt now
await si.scheduleShutdown(seconds: 60);
await si.cancelShutdown();

await si.setLaunchAtStartup(true, args: '--minimized');

await si.tray.show(iconPath: SystemTray.assetPath('assets/tray.ico'), tooltip: 'Downloader');
await si.tray.setMenu([
  const TrayMenuItem(id: 'show', label: 'Show'),
  const TrayMenuItem.separator(),
  const TrayMenuItem(id: 'quit', label: 'Quit'),
]);
si.tray.onClick = si.restoreWindow;
si.tray.onMenuItemSelected = (id) { /* ... */ };
await si.tray.setProgress(42);                  // null clears
await si.minimizeToTray();
await si.flashWindow();
```

Example app: `cd example && flutter create --platforms=windows,macos,linux . && flutter run`.

## Feature matrix and exact commands

| Feature | Windows | macOS | Linux |
|---|---|---|---|
| openFile | ✅ FFI `ShellExecuteW(L"open")` | ✅ `open <path>` | ✅ `xdg-open <path>` |
| revealInExplorer | ✅ FFI `SHOpenFolderAndSelectItems`, fallback `explorer.exe /select, <path>` | ✅ `open -R <path>` | ✅ `gdbus call --session --dest org.freedesktop.FileManager1 --object-path /org/freedesktop/FileManager1 --method org.freedesktop.FileManager1.ShowItems "['file://…']" "''"` (or `dbus-send`); otherwise `xdg-open <dir>` and `canRevealInPlace=false` |
| copyToClipboard | ✅ Flutter `Clipboard` | ✅ | ✅ |
| listVolumes | ✅ `GetLogicalDriveStringsW`, `GetDriveTypeW`, `GetVolumeInformationW`, `GetDiskFreeSpaceExW` | ✅ `getfsstat` + `statfs` (libSystem); boot name from the `/Volumes` symlink | ✅ `/proc/self/mounts` (`getmntent`) + `statvfs64`; labels `/dev/disk/by-label`; removable `/sys/class/block/*/removable` |
| freeSpaceOf | ✅ `GetDiskFreeSpaceExW` (caller quota) | ✅ `statfs` `f_bavail·f_bsize` | ✅ `statvfs64` `f_bavail·f_frsize` |
| watchVolumes / onLowSpace | ✅ Dart polling, change-only, edge-triggered + hysteresis | ✅ | ✅ |
| scheduleShutdown | ✅ FFI `InitiateSystemShutdownExW` (fallback `shutdown /s /t N`) | ✅ detached `osascript -e 'delay N' -e 'tell application "System Events" to shut down'`, pid tracked | ✅ `shutdown -h +⌈N/60⌉`; fallback in-process timer → `systemctl poweroff` |
| cancelShutdown | ✅ FFI `AbortSystemShutdownW` (fallback `shutdown /a`) | ✅ SIGTERM to the tracked osascript pid | ✅ `shutdown -c` |
| isShutdownPending | ✅ persisted record | ✅ `ps -p <pid> -o comm=` = osascript | ✅ `/run/systemd/shutdown/scheduled` |
| sleepNow | ✅ FFI `SetSuspendState(FALSE,FALSE,FALSE)` | ✅ `pmset sleepnow` | ✅ `systemctl suspend` / `loginctl suspend` |
| setLaunchAtStartup | ✅ FFI `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | ✅ `~/Library/LaunchAgents/<appId>.plist` (`RunAtLoad`) | ✅ `$XDG_CONFIG_HOME/autostart/<appId>.desktop` (`$APPIMAGE` aware) |
| Tray icon + menu | ✅ `Shell_NotifyIconW` + `TrackPopupMenu`, re-added on `TaskbarCreated` | ✅ `NSStatusItem` + `NSMenu` (right / ctrl-click) | ✅ AppIndicator/SNI (`libayatana-appindicator3.so.1`), fallback `GtkStatusIcon` |
| Tray progress | ✅ native taskbar progress (`ITaskbarList3`) + tooltip | ⚠️ emulated: status item title `42%` | ⚠️ emulated: indicator label |
| Left click restores | ✅ | ✅ | ⚠️ AppIndicator: no (`trayLeftClickRestores=false`; use a "Show" item, middle click = first item). GtkStatusIcon: yes |
| minimizeToTray / restore | ✅ `ShowWindowAsync` | ✅ `orderOut` / `makeKeyAndOrderFront` | ✅ `gtk_widget_hide` / `gtk_window_present` |
| flashWindow | ✅ `FlashWindowEx` | ✅ `requestUserAttention` | ⚠️ X11 urgency hint; `false` under Wayland |

## Platform notes

* **Windows** – the tray icon file must be `.ico`; without it the runner icon (resource 101) is used.
  Modern Standby (S0ix) devices may ignore `SetSuspendState`.
* **macOS** – disable App Sandbox (`com.apple.security.app-sandbox` = `false` in both
  entitlements files), otherwise `Process.run` and LaunchAgents are blocked. Add
  `NSAppleEventsUsageDescription` to `Info.plist`. A PNG whose name contains `Template`
  is shown as a tinted menu-bar template image. Numbers match `df -k`.
* **Linux** – optional runtime package `libayatana-appindicator3-1` (GNOME: AppIndicator
  extension). `shutdown` / `systemctl suspend` are allowed by polkit for the active local
  session. `shutdown` has minute granularity. Numbers match `df -B1` *Avail*.

`freeSpaceOf` returns `-1` when unknown. `DiskVolume.freeBytes` is what the user can write;
`usedBytes = totalBytes − freeBytes`; `usagePercent` is 0..100.
